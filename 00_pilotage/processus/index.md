## Comment utiliser un processus

Lorsqu'une demande déclenche un processus :
1. Identifier le code du processus correspondant dans ce tableau.
2. Ouvrir le fichier du processus.
3. Suivre les étapes dans l'ordre, sans en sauter.
4. Respecter les règles de décision à chaque embranchement.
5. Produire tous les livrables attendus avant de clore le processus.

Les agents doivent vérifier cet index avant toute opération récurrente pour savoir si un processus existe déjà.
