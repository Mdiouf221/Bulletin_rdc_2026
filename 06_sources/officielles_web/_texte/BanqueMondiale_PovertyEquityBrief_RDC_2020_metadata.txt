CONTENU

Ce document est un brief de 2 pages de la Banque mondiale sur la pauvreté en RDC.
Données de référence (enquête ménages 2012) :

PAUVRETÉ :
  Seuil national de pauvreté      : 63,9 % (2012) — 44,1 millions de personnes
  Seuil international $1,90/j     : 76,6 % (2012) — 52,9 millions
  Seuil intermédiaire $3,20/j     : 91,0 % (2012) — 62,8 millions
  Seuil revenu moyen sup $5,50/j  : 97,7 % (2012) — 67,5 millions
  Pauvreté multidimensionnelle    : 82,4 %
  Note : taux national passé de 69,3 % (2005) à 64 % (2012) ; mais le nb de pauvres a augmenté de 7M

INÉGALITÉS :
  Indice de Gini : 42,1 (2012) — stable entre 2004 et 2012

CROISSANCE :
  Croissance PIB/habitant annualisée : 2,55 % (2004-2012)
  Croissance consommation/habitant : 9,83 % (2004-2012)
  Croissance bottom 40 % : 9,78 %
  Shared prosperity premium : -0,05 % (quasi-nul → croissance bénéficiant peu aux plus pauvres)

DÉSAGRÉGATIONS CLÉS :
  Population urbaine sous $1,90/j  : 56 % | Rural : 89 %
  Femmes sous $1,90/j              : 76 % | Hommes : 77 %
  0-14 ans sous $1,90/j            : 82 %
  Sans éducation (16+)             : 83 % sous $1,90/j
  Éducation tertiaire (16+)        : 24 % sous $1,90/j

PAUVRETÉ MULTIDIMENSIONNELLE (2012) :
  Pauvreté monétaire (<$1,90)      : 76,6 %
  Au moins 1 enfant non scolarisé  : 8,0 %
  Aucun adulte n'a achevé primaire  : 22,5 %
  Pas d'accès à l'eau potable      : 47,9 %
  Pas d'accès à l'assainissement   : 80,0 %
  Pas d'accès à l'électricité      : 83,0 %

AVERTISSEMENT MÉTHODOLOGIQUE (mentionné dans le document) :
  - Comparabilité des enquêtes 2004/05 et 2012 limitée (méthodologie recomputée)
  - Pas d'IPC cohérent entre 2004/05 et 2012 (prix unitaires utilisés comme proxy)
  - Données territoriales non représentatives (Kinshasa seulement enquêtée en 2018)
